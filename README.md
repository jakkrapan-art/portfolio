## Visitor analytics

The site supports cookie-free GoatCounter analytics. Visitors do not need to
sign in or accept an access cookie. The analytics dashboard is separate from
the portfolio site and is only visible to you after signing in to GoatCounter.

1. Create a GoatCounter site and copy its site code. For example, the code is
	`portfolio` for `https://portfolio.goatcounter.com`.
2. Copy `.env.example` to `.env.local`.
3. Set `REACT_APP_GOATCOUNTER_CODE` to your site code.
4. Run `npm run build` and deploy the generated `build` folder.

Analytics are disabled in development and when the environment variable is
empty. Once deployed, open the GoatCounter dashboard to see visits, pages,
referrers, countries, and devices. Tracking itself does not display a widget
or visitor count on the portfolio page.
